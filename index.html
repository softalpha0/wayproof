Wayproof · Proof Reports

Wayproof checks whether a crypto project's how-to guide still works: Kane CLI follows each step in a real browser, Claude proposes a fix when a step fails, and Kane re-runs to prove it. Wayproof never connects a wallet, signs or sends anything; wallet steps are marked "not checked".

These are real checks of real guides, each a dated snapshot. Every verdict quotes Kane's own output. Kane's sealed evidence packs stay private because they contain Kane account details; each report links Kane's raw output and Kane's own run page instead. Source and how to run it yourself: https://github.com/softalpha0/wayproof
